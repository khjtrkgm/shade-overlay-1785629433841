# Shade Overlay

تطبيق اندرويد حقيقي يرسم طبقة شادر/لون فوق الشاشة باذن SYSTEM_ALERT_WINDOW (حقيقي).
لا يعدل اي تطبيق اخر - الطبقة تعرض فقط.

## المزايا
- قائمة التطبيقات المثبتة (اذن QUERY_ALL_PACKAGES حقيقي)
- طبقة شاشة بخيارات شادر: تعتيم/دافئ/بارد/تدرج/نبض/خطوط/رمادي
- تغيير لون الطبقة والشفافية
- واجهة سوداء وبيضاء

## البناء
يتم بناء APK تلقائيا عبر GitHub Actions عند الرفع. حمل APK من صفحة Releases.

## الصلاحيات الحقيقية
- SYSTEM_ALERT_WINDOW : عرض الطبقة فوق التطبيقات
- QUERY_ALL_PACKAGES : سرد التطبيقات
- FOREGROUND_SERVICE : ابقاء الطبقة تعمل
- POST_NOTIFICATIONS : اشعار التشغيل
